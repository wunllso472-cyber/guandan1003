    A SMALL COMPONENT. A GOOD START.

    把这份默契，接入你的牌局。

    这是一个独立的加载进度组件演示。所有卡牌与动效均由 CSS 和内联 SVG 绘制，无外部依赖，断网也能使用。

    如何体验

    点击或拖动进度条调节进度；点击“开始演示”自动推进。聚焦进度条后，方向键调节 1%，Shift + 方向键调节 10%，Home / End 跳至起点 / 终点。

    接入真实加载

    在资源加载回调中调用 setProgress，传入 0–100 的数值。自动播放只用于演示，不代表实际资源加载进度。

    guandanProgress.setProgress(70);
guandanProgress.setProgress(100, {
  animate: true, duration: 600
});
guandanProgress.play();
guandanProgress.pause();
guandanProgress.reset();

window.addEventListener('guandan:complete', () => {
  console.log('Ready to play!');
});
    Vanilla JavaScript

    支持手机触控、键盘操作与系统减少动态效果设置。右上角可切换深浅外观。
